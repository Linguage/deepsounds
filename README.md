# deepsounds · DSH

在 DeepSeek Harness 侧栏打开「deepsounds」，可切换网易云音乐、小宇宙和 B 站。切换来源或 DSH 面板时，当前音频可继续播放。

搜索框右侧的「平台设置」可分别开启或关闭三个平台，默认全部开启。关闭平台后会隐藏其入口并停止相关播放和提醒，收藏和待播队列可在重新启用后继续使用。

## 安装

适用于 DSH 0.2.x 的 Desktop 或 Web 界面。从 [GitHub Releases](https://github.com/Linguage/deepsounds/releases/latest) 下载 `deepsounds-dsh-*.tgz`，在 DSH 的「插件 → 添加插件」填入下载文件的绝对路径并启用。安装后从侧栏打开「deepsounds」。

从 0.10.0 或更早版本升级时，先停用旧插件，再安装 `deepsounds-dsh`。在同一个 DSH 环境中，本机收藏与队列会保留。从 0.9.x 升级或登录过期时，平台账号需要重新扫码登录。

在支持右侧标签的 DSH 版本中，打开一段对话，展开右侧栏，在「开始」页选择「deepsounds」。已有标签时可用右侧栏的「＋」打开「开始」。右侧与全尺寸界面共用播放器，切换视图或收起右侧栏时，音频可继续播放。

窄窗口或窄侧栏会收起内容导航。点击搜索框左侧的菜单按钮，即可打开抽屉并切换来源、分类或账号。

点击搜索框右侧的「检查插件更新」图标，可查看当前版本和 GitHub 最新正式版本。发现新版后，可点击「安装更新」交给 DSH 插件管理器，也可下载安装包后手动安装。若 DSH 提示重启，退出并重新打开即可生效。

## 网易云音乐

搜索歌曲、歌手和歌单，或粘贴网易云公开歌单链接。用网易云音乐 App 扫码确认后，可查看自己创建和收藏的歌单。播放条可控制播放、进度和音量，点「歌词」可打开沉浸歌词页。

## 小宇宙

首页显示公开播客榜单，可按节目名称搜索，也可粘贴小宇宙节目、单集链接或 `xyzfm.link` 分享短链。游客搜索和榜单来自 [XYZ Rank](https://xyzrank.top/)，节目内容和音频来自小宇宙。游客可浏览公开页显示的最近单集，播放条的「单集简介」会显示节目原页提供的文字。

在小宇宙来源底部点击「扫码登录」，用小宇宙 App 扫码确认。登录后打开「我的订阅」，并可用小宇宙原生搜索查节目或单集、分页浏览节目档案。侧栏「播放列表」读取手机 App 播放器的列表，按原顺序展示；打开页面或点击「重新同步」时读取最新列表。它是只读的。插件播放小宇宙提供的公开音频。

## 收藏和本机队列

点击歌曲或单集旁的心形按钮即可收藏。侧栏「收藏歌曲」「收藏单集」可以查看对应来源的收藏；节目详情里的「收藏节目」收藏的是整档播客。

点击条目旁的加入按钮，将歌曲或单集加入本机队列。点底部播放条的列表图标查看、播放或移除队列里的项目，两个来源可以混合播放。收藏和手动加入、尚待播放的项目保存在当前 DSH 浏览器环境里。

## 哔哩哔哩

登录后打开视频，鼠标移到画面内会显示播放栏，停留约三秒会自动隐藏。播放栏提供默认尺寸、影院模式和全屏。画质与「同步观看记录到 B 站」位于播放栏的设置菜单。勾选同步后，播放期间、暂停或关闭时会向该账号提交进度。旧版外链播放器的播放进度不在插件内保存。若账号播放器未能加载，可以点「在哔哩哔哩打开」。

切换到「B 站」后，在顶部搜索视频或 UP 主，点视频封面可在插件内播放，点 UP 主可浏览其近期投稿。

视频卡片显示发布时间。扫码登录后，视频详情可点赞、选择 B 站收藏夹、关注 UP 主，也可取消这些操作。UP 主投稿页也有关注按钮。这些操作会同步到登录的 B 站账号。

扫码后可打开「关注的 UP 主」或「关注更新」。在「关注更新」点「开启提醒」，DSH 运行并保持登录期间约每 5 分钟检查新视频。首次开启以当前列表为起点，之后的新投稿会显示未读数。系统通知可用且已授权时，也会弹出通知。

切换到「B 站」，用哔哩哔哩 App 扫码并确认。登录后可查看自己创建的收藏夹及其中的视频，以及账号的「稍后再看」。点击视频封面会打开插件内的 B 站播放器，正在播放的歌曲或播客会暂停。需要 B 站登录或无法嵌入的视频，可点击「在哔哩哔哩打开」前往原页。

三个来源的登录各自独立。扫码后，同一 DSH 桌面配置或同一浏览器地址会在重启后恢复登录。平台凭据保存在 DSH 私有数据目录中，浏览器只保存随机会话标识。点击「退出登录」会清除对应会话。平台授权失效、浏览器数据被清除或 90 天未使用该账号后，需要重新扫码。

## 开发

```sh
npm test
npm run serve    # 仅监听 127.0.0.1:7346
npm run package  # 生成本地安装包
```

`lib/netease.js`、`lib/xiaoyuzhou.js` 和 `lib/bilibili.js` 分别适配三个来源；`lib/account.js` 管理登录会话；`web/` 处理共用的导航、内容和播放器。平台接口和网页结构可能变化。

接口参考：[mygo-music-netease](https://github.com/sogud/mygo-music-netease)、[dsh-xiaoyuzhou](https://github.com/jerryqx/dsh-xiaoyuzhou) 和哔哩哔哩网页客户端。二维码使用 Kazuhiko Arase 的 [QR Code Generator](https://github.com/kazuhikoarase/qrcode-generator) 2.0.4，许可见 `lib/vendor/LICENSE-qrcode.txt`。本项目与这些平台均无官方关联。

B 站账号播放器使用 [dash.js](https://github.com/Dash-Industry-Forum/dash.js) 5.2.0，许可见 `lib/vendor/LICENSE-dash.js.md`。
